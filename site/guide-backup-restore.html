Detailed guide

Backup and restore.

Keep a portable copy of your Docketo records and receipt images, ready for a new phone or an unexpected problem.

All guidesNext: Cloud Sync
Create a backup

Export before you need it.

Open Docketo Settings and find Backup. Choose the option to create or export a backup. The backup includes your purchase records and attached receipt images, so allow enough time and device storage for it to finish.

Choose password protection whenever possible. The password protects the backup file; it cannot be recovered by Docketo if you forget it.

Where to keep it

  • A secure cloud-drive folder you control
  • A computer you back up regularly
  • An encrypted external drive
  • More than one secure location for important records

Avoid saving a protected backup only on the same phone you are trying to protect.

Before changing phones

  1. Create a fresh password-protected backup on the old phone.
  2. Confirm the file has been saved somewhere you can access from the new phone.
  3. Install Docketo on the new phone.
  4. Use Restore from Settings and select the backup.
  5. Check a few records and receipt images before deleting anything from the old phone.
Moving devices

Back up first. Restore second.

Do not depend on a transfer finishing perfectly. A Docketo backup gives you a second, independent way to bring over your purchases and receipt images.

Restore

Choose merge or replace carefully.

Open Settings, select Restore and choose your Docketo backup. Enter its password when asked. Before confirming, read the restore mode carefully.

Merge keeps your current local records and adds records from the backup. Replace removes the current local records and uses the backup instead. Merge is generally the safer choice when you are unsure.

Use Replace only when

  • You want this device to match the backup exactly
  • You have checked that the backup is complete
  • You do not need the current local-only records
  • You have made a current backup before continuing

If a backup will not restore

  • Check that you selected a Docketo backup file.
  • Confirm the password is correct, including capitals and symbols.
  • Make sure the file finished downloading or copying.
  • Check that there is enough free device storage.
  • Try copying the backup to local phone storage before restoring.
A final safety rule

Cloud Sync is helpful, but keep your own backup.

Cloud Sync can keep account-linked records available between devices, but a password-protected backup is still your independent copy. Use both for important information.
