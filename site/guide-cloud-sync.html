Detailed guide

Set up Cloud Sync.

Use Cloud Sync to keep your account-linked Docketo records available when you use another device.

All guidesPremium guide
Before you begin

Check the three requirements.

Cloud Sync is a Premium feature. You need an active Premium entitlement, a signed-in Docketo account and an internet connection. Guest-only records are not ready for account-linked sync until you sign in and turn Cloud Sync on.

Ready to sync?

  • Premium is active in Docketo
  • You are signed in to the intended Docketo account
  • Internet is available
  • You have made a current local backup

Turn on Cloud Sync

  1. Open Docketo Settings.
  2. Confirm that you are signed in.
  3. Open the Cloud Sync area.
  4. Turn on Cloud Sync.
  5. Select Sync now and wait for it to complete.

Keep the app open until the first sync has finished, especially if you have many receipt images.

First sync

Start from the device with your records.

On the device that already holds your Docketo information, sign in, enable Cloud Sync and use Sync now. This makes it the best starting point before setting up another device.

Second device

Use the same account, then sync.

Install Docketo on the second device. Sign in using the exact same email or Google account, activate Premium if required, turn on Cloud Sync and select Sync now. Give the app time to download records and images.

Do not create a second account accidentally. If the account details differ, the devices are not looking at the same cloud records.

Good syncing habits

  • Sync after important additions or edits
  • Use Wi-Fi for a large receipt library
  • Let a sync finish before closing the app
  • Keep a separate backup before a phone change

When records do not appear

  1. Confirm both devices are signed in to the same Docketo account.
  2. Check that Premium is active.
  3. Confirm Cloud Sync is switched on on both devices.
  4. Check internet access and use Sync now.
  5. Wait briefly, then reopen the purchase list.
  6. Check whether the record is hidden by a search or warranty filter.
Still stuck?

Protect your local data first.

Make a backup before changing settings or reinstalling the app. Then contact support with the email account type you used, the device models and a short description of what did not sync. Never include your password.
