Support

Help with Docketo.

For support, contact lachlanmaharjan7@gmail.com.

Include these details

  • Docketo app version
  • Android version and phone model
  • The screen where the issue happened
  • Steps that reproduce the issue
  • A screenshot, provided it does not expose private receipt information

Common checks

  • Confirm notification permission is enabled
  • Use the newest verification or password-reset email
  • Check junk or spam folders for Firebase emails
  • Export a backup before uninstalling or clearing app data
  • Install Play Billing test builds from a Google Play testing track

Privacy reminder

Do not send passwords, backup passwords, payment-card information, account security codes or private receipt images by email.
