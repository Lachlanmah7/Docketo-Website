# Video 3 — Backup and Restore

**Recommended length:** 2–4 minutes

## Introduction

Docketo stores purchase information locally, so creating a backup is important before changing phones, uninstalling the app or clearing app data.

## Export

1. Open **Settings**.
2. Choose **Export backup**.
3. Select password protection where available.
4. Choose a safe location for the backup.
5. Confirm that the backup file has been created.

## Restore

1. Install and open Docketo.
2. Open **Settings**.
3. Choose **Restore backup**.
4. Select the backup file.
5. Enter the backup password if required.
6. Choose the appropriate restore option.
7. Confirm that purchases and receipt images are available.

## Safety message

Keep the backup password somewhere safe. Docketo support cannot recover a forgotten backup password.

Always verify the backup before deleting the original app data.
